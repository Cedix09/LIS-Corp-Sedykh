LIS Corporation WebSite

## Описание
Веб-приложение корпоративного сайта LIS Corp, реализующее:

главную страницу с динамическим контентом
систему авторизации и регистрации пользователей
новостной модуль с категориями и комментариями
форум с темами, ответами и системой рейтинга
административную панель для управления контентом

## Технологии
- PHP 7.4
- MariaDB 10.5
- Bootstrap 5
- HTML5 / CSS3
- PDO (безопасная работа с БД)

## Функциональность
Пользовательская часть
- Регистрация и авторизация
- Просмотр новостей
- Комментирование новостей
Форум:
- создание тем
- ответы в темах
- лайки / дизлайки
- выбор лучшего ответа
- поиск и фильтрация

## Административная часть
- Добавление / удаление новостей
- Назначение лучшего ответа
- Управление контентом

## Безопасность
- Валидация всех форм на сервере
- Защита от SQL-инъекций (PDO prepared statements)
- Защита от XSS (htmlspecialchars)
- Ограничение действий по ролям пользователей
- Антиспам (ограничение создания тем по IP)

## Установка и запуск
1. Клонирование проекта: Склонируйте репозиторий с исходным кодом в корневую директорию вашего локального сервера (например, в папку domains для OpenServer).
   ```
   git clone https://github.com/Cedix09/LIS-Corp-Sedykh.git
   ```
2. Импорт базы данных:
3. Создайте новую базу данных с именем lis_corp.
4. Выберите созданную базу и во вкладке «Импорт» выберите файл sql/create_database.sql из папки проекта.
5. Откройте файл config/database.php.
6. Проверьте и при необходимости отредактируйте параметры подключения: укажите имя базы данных (lis_corp), логин и пароль пользователя (по умолчанию для OpenServer — root без пароля).
7. Откройте http://localhost/LIS-Corp-Sedykh/

## Роли пользователей
| Роль    | Возможности                                                       |
|---------|-------------------------------------------------------------------|
| admin   | Полный доступ (админ-панель, лучший ответ, управление новостями)  |
| user    | Работа с форумом, комментариями и личными данными                 |

## Структура проекта
/config          — подключение к БД  
/models          — модели (например User)  
/styles          — CSS стили  
/admin           — админ-панель  
index.php        — главная страница  
forum.php        — форум  
topic_view.php   — страница темы  
news.php         — новости
