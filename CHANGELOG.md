# CHANGELOG

## [1.0.0] - 2026-05-04

### Добавлено
- Главная страница с динамическими данными (company_stats, галерея)
- Система авторизации и регистрации пользователей
- Роли пользователей (admin, user)
- Новостной модуль:
  - категории новостей
  - просмотр списка и полной статьи
  - комментарии
  - счётчик просмотров
- Форум:
  - создание тем
  - ответы в темах
  - поиск и фильтрация
  - лайки / дизлайки
  - выбор лучшего ответа (админ)
- Страницы:
  - О компании
  - Контакты (с картой)
  - FAQ
  - Политика конфиденциальности
  - Правила форума
- Форма обратной связи (с сохранением в БД)

### Исправлено
- Исправлены ошибки валидации форм
- Исправлены ошибки SQL-запросов (PDO)
- Исправлены проблемы с навигацией в админке
- Исправлена логика голосования (лайки/дизлайки)

### Безопасность
- Валидация всех форм на сервере
- Защита от SQL-инъекций (PDO prepared statements)
- Защита от XSS (htmlspecialchars)
- Ограничение доступа по ролям (admin / user)
- Ограничение действий по IP (антиспам)
